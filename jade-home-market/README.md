# 제이드의 내집마련

서울·경기·인천 아파트 매매 실거래 조회 화면과 기존 예시 시안입니다. Python 3.12 이상만으로 서버를 실행할 수 있습니다. 텔레그램 봇과 별개입니다.

## 실행

저장소 루트에서:

```bash
cd jade-home-market
python3 server.py --host 127.0.0.1 --port 4173
```

서버 프로세스에 `DATA_GO_KR_SERVICE_KEY`를 환경변수로 주입하세요. 클라우드에서는 시크릿 설정에 등록하고 HTTPS 목적지를 `apis.data.go.kr`로 지정합니다. 일반 로컬 환경에서는 OS의 보안 설정 또는 개인 환경변수를 사용합니다. `.env` 파일을 자동으로 읽지는 않습니다. 키를 소스, Git, 브라우저 입력창, URL 또는 채팅에 넣지 마세요.

실거래 모드는 서버 실행이 필요합니다. `python -m http.server`와 GitHub Pages는 API를 처리하지 못합니다. 외부 배포에서는 운영 서버/리버스 프록시의 인증, TLS, 요청 제한을 추가하고 서버를 프로세스 관리자로 실행하세요. 이 서버는 단일 사용자 개발용입니다. 기존 배포 URL은 이번 Git push로 자동 변경되지 않습니다.

## 실거래 모드

기본 화면은 국토교통부 실거래 조회입니다. 시·구와 마지막 조회월, 조회 범위(3/6/12개월)를 선택합니다. 기본값은 서울 송파구·직전 달까지 3개월입니다. 한 번의 조회는 선택한 시·구만 포함하며 수도권 전체 동시 집계가 아닙니다. 행정구역 개편 지역은 해당 거래월의 코드와 대조가 필요합니다. 지역 목록의 포함만으로 해당 코드의 최신 유효성을 보장하지 않습니다.

- 서버가 `RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`를 호출하고 XML을 JSON으로 변환합니다. 인증키는 브라우저로 내려가지 않습니다.
- 월별 응답을 페이지 끝까지 조회합니다(1,000건/페이지, 최대 20페이지). 실패하면 부분 결과로 성공 처리하지 않습니다. 메모리 캐시는 15분이며 재시작하면 사라집니다.
- 해제 표시·해제일이 있는 계약은 제외합니다. 각 조회는 응답 당시의 정정 상태를 사용하며 과거 정정 추적 DB는 아직 없습니다.
- 법정동·지번·단지명·정확한 전용면적으로 묶습니다. 공식 단지 식별자 매핑은 미완료입니다. 다른 계약을 지우지 않도록 같은 가격·날짜만으로 중복 제거하지 않습니다.
- 목록의 가격은 조회 기간 내 최신 계약 가격, 등락률은 마지막 두 달의 중위가격 비교입니다. 양쪽 모두 3건 이상일 때만 계산하고, 부족하면 `표본 부족`을 표시합니다. 최신 월에 거래가 없으면 최근 거래일을 함께 확인하세요.
- 차트는 월별 중위가격과 개별 거래 점을 표시합니다. 거래 없는 달은 연결선을 끊고 거래 건수를 표시합니다. 일·주·분기·반기·년·5년·10년 집계는 실거래 모드에서 비활성화했습니다.
- 대장 단지 식별, 활성 전월세 매물 수, 시장 심리, KRES는 미연결입니다. 전체 단지·전용면적 조합이 기본이고 임의로 대장 단지를 지정하지 않습니다.
- API 실패는 오류로 표시하며 가상 데이터로 자동 대체하지 않습니다. 신고 시차, 층·향·동 구성 차이를 반영한 투자 분석은 아직 제공하지 않습니다.

## 검증

저장소 루트에서:

```bash
python3 -m unittest discover -s jade-home-market/tests -v
```

XML 변환·금액·면적·날짜, 해제 제외, 오류 응답, 페이지네이션·캐시, 부분 실패 방지, 요청 검증, 비공개 파일 접근 차단을 검사합니다.

브라우저 검증(Playwright와 Chromium이 설치된 개발 환경):

```bash
# 먼저 별도 터미널에서 서버를 4174 포트로 실행
cd jade-home-market
python3 server.py --port 4174
# 저장소 루트의 다른 터미널에서
node jade-home-market/tests/test_ui.cjs
```

브라우저 검사는 모의 거래를 사용해 면적별 집계·금액 단위·거래 공백·최소 표본·HTML 이스케이프·관심 저장·모바일 레이아웃을 확인합니다. 실제 API 성공을 대신하지 않습니다.

현재 실제 호출 결과: 등록된 클라우드 시크릿은 존재하지만 국토부가 HTTP 400 / 오류 코드 10 (`INVALID_REQUEST_PARAMETER_ERROR`)으로 응답했습니다. `11710`과 `202501`/`202609` 등으로 재현했습니다. 인증키 자체의 유효성이나 실제 데이터 수신 성공은 확인되지 않았습니다. 공공데이터포털의 동일 서비스 미리보기에서 법정동 코드 `11710`, 계약년월 `202609`, 페이지 `1`, 한 페이지 결과 `1`로 요청해 결과 코드를 대조해야 합니다. 키를 로그에 남기지 마세요.
