# 구현 현황 업데이트

매매 실거래 서버 어댑터와 실제 조회 화면을 구현했습니다. 실행·현재 API 오류·지원 범위는 README.md를 참고하세요. 아래 내용은 복구 당시 설계안입니다. 전월세 매물·심리·KRES는 미연결입니다.

# 데이터·AI 연동 검토안

검토 상태: 설계 초안. 이 환경의 HTTPS 프록시가 docs.x.ai, www.data.go.kr, www.reb.or.kr 요청을 CONNECT 403으로 차단했다. 최신 API 제공 여부·요금·호출 한도·라이선스를 공식 문서에서 확인하지 못했으므로 아래 후보를 '연동 확인 완료'로 보지 않는다. 현재 HTML/JS는 외부 API를 호출하지 않는다.

## KRES 연결 경로

1. 사용자가 제공하는 KRES 공유/소개 링크로 제품 유형과 제작자를 확인한다. 링크 자체가 API는 아니다.
2. 제작자가 공식 API/웹훅을 제공하고 사용 권한이 있으면 서버에서 호출한다. 인증 방식, 응답 형식, 근거 인용, 비용을 확인한다.
3. 외부 호출을 지원하지 않으면 KRES 자체 연동은 불가능할 수 있다. 제작자가 공개하거나 사용을 허용한 분석 기준을 사용해 별도 xAI 분석 파이프라인을 설계한다. 이를 KRES가 분석한 결과라고 표시하지 않는다.
4. 토큰/키는 서버 보안 설정에만 저장한다. 프론트 코드/로컬 스토리지에 넣지 않는다. 인증된 브라우저 세션 복제나 비공개 엔드포인트 호출을 구현하지 않는다.

## 심리 한 줄

지역별 공표 지표 + 거래량 + 매물 변화(확보 시)를 날짜와 함께 입력. AI는 근거를 요약하며 없는 값을 생성하지 않는다. 공표 주기가 다른 데이터는 각각 기준일을 유지한다. 뉴스·SNS는 별도 보조 신호로만 사용하며 매수자 전체의 심리라고 간주하지 않는다.

응답 예: {region, as_of, label: 관망/매수우세/매도우세/혼조/판단보류, summary, evidence:[{source,period,value}], coverage, generated_at}. 데이터 부족·오래된 데이터는 판단 보류. 모델 출력은 스키마 검증 후 표시.

## 주목 단지

상승 예측이나 매수 추천과 구분한다. 거래량 변화, 동일 면적 가격 변화, 매물 변화, 거래 표본 수에 대한 재현 가능한 지표로 후보를 추린 뒤 AI가 이유를 요약한다. 후보별 단지 ID, 면적, 지표 기간, 근거, 최신 시각과 데이터 충분 여부를 저장한다. 대장 여부는 별도 속성이다. 현재 시안은 대표 후보의 카드 배치 예시만 표시하며 추천 결과가 아니다.

## 매물 증감 계산

- 활성 매물 스냅샷 N(t): 동일 공급자·동일 범위·동일 유형(전세/월세)·동일 중복 제거 기준.
- 증감량 = N(t) - N(t0), 증감률 = 증감량 / N(t0) × 100. 기준값 0이면 비율 미산출.
- 유형별 중복 광고/동일 주택 중복을 구분. 중복 제거가 불가능하면 '광고 건수'로 명시한다.
- 수집 실패/누락은 0건으로 처리하지 않는다. 관측값이 없으면 미집계.
- 일·주·월·분기·반기·연·5년·10년 비교는 실제 보유한 기준일 스냅샷에 한해 제공. 오늘 수집을 시작해 과거 10년 매물 이력을 만들 수 없다.
- 매물 감소가 곧 계약 체결이나 강세를 뜻하지 않는다. 광고 종료·중개사 변경·공급자 커버리지 변동도 영향을 준다.

## 서버 구성 제안

공식 API/공급자 → 주기적 수집·원본 보존 → 단지 식별자 및 지역/면적 정규화 → 집계 DB → 근거 패키지 → AI 요약 → 캐시된 사이트 API.
브라우저가 API 키를 보유하거나 매번 AI를 직접 호출하지 않는다. 거래 데이터는 취소·정정을 재수집하고, 공표 지표는 해당 공표 주기에 맞춰 갱신한다. 매물 스냅샷은 공급자 계약과 수집 주기에 따른다.

서비스 내부 API 초안(외부 공급자의 실제 엔드포인트 아님):
- GET /api/market/sentiment?region=... : 심리/근거/기준일
- GET /api/market/watchlist?region=... : 주목 단지/선정 이유
- GET /api/market/rent-inventory?region=...&period=... : 전세·월세 활성 매물과 비교값

## 다음에 필요한 확인

KRES 공유 링크, API 소개 페이지 또는 제작자 문서. 그리고 네이버페이/매물 공급자 중 합법적 조회·이력 제공 경로 선정. 필요한 인증 키는 실제 공급자를 확정한 뒤 보안 설정으로 입력한다. 토큰을 채팅에 요청하지 않는다.
