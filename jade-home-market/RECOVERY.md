# 시안 복구 기록

이 파일들은 이전 클라우드 작업 ‘제이드의 내집마련’(01a156db-5921-717d-b1aa-9cc635e700ac)의 파일 생성 명령과 후속 수정 기록을 순서대로 적용하여 복구했습니다. 이전 서버의 파일시스템을 직접 복사한 것은 아니며, 이후 ‘시안 재구성 완료’ 대화에서 배포한 버전과 바이트 단위로 동일함은 확인하지 않았습니다.

복구 범위: index.html, style.css, app.js, data.js, README.md, API_PLAN.md. desktop.png, mobile.png, mobile-chart.png는 현재 환경에서 새로 촬영했습니다.

현재 브라우저 검증: 브랜드명, 36px 행 20개, 53개 샘플 페이지 이동, 단지 선택, 8개 기간, 주목 단지 선택, 지역 범위, 미연결 값 표시, 모바일 가로 넘침 없음, JavaScript 오류 없음.

현재 데이터는 전부 가상 예시입니다. 외부 데이터 API, KRES, 실제 시장 심리와 매물 수 집계는 연결되지 않았습니다. 이전 배포 주소는 HTTP 401 로그인 화면으로 응답하므로 인증된 페이지 내용은 확인하지 못했습니다.

실행: cd jade-home-market && python3 -m http.server 4173 --bind 127.0.0.1
